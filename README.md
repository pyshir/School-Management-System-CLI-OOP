# 🏫 School Management System

## Jahid, Whatsapp: 8801309495010 

A simple **School Management System** built with Python using Object-Oriented Programming (OOP). This project allows you to manage students, teachers, and library operations through a command-line interface (CLI).

## ✨ Features

### 👨‍🎓 Student Management
- Add Student
- Remove Student
- Student Payment
- Add Student Marks
- Generate Student Result (`result.txt`)

### 👨‍🏫 Teacher Management
- Add Teacher
- Remove Teacher
- Assign Subject
- Provide Salary

### 📚 Library Management
- Add Book
- Remove Book
- Borrow Book
- Return Book
- Add Fine

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Command Line Interface (CLI)
